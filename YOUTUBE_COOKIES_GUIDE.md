# YouTube Cookies Setup Guide

## Why Cookies Are Needed

YouTube blocks downloads from automated tools to prevent bot abuse. When downloading age-restricted or certain types of videos, YouTube requires authentication via cookies.

**Error Message:** `"Sign in to confirm you're not a bot"`

This happens when:
- Downloading age-restricted videos
- Too many requests from the same server
- Region-restricted content
- Premium content

## How to Get YouTube Cookies

### Option 1: Using Browser Extension (Easiest)

#### Chrome/Brave/Edge:
1. Install extension: [Get cookies.txt](https://chrome.google.com/webstore/detail/get-cookiestxt-locally/cclelndtbojalistcbflkgkobqgfblbl)
2. Go to youtube.com
3. Log in to your account
4. Click the extension icon
5. Copy the cookies text

#### Firefox:
1. Install extension: [cookies.txt](https://addons.mozilla.org/en-US/firefox/addon/cookies-txt/)
2. Go to youtube.com
3. Log in to your account
4. Click the extension icon
5. Copy the cookies text

### Option 2: Manual Export via Node.js Script

We provide a script to export cookies: `backend_python/export_youtube_cookies.js`

```bash
node backend_python/export_youtube_cookies.js
```

This will open your browser, let you log in, and extract cookies automatically.

### Option 3: Using DevTools (Advanced)

1. Go to https://www.youtube.com
2. Open DevTools (F12)
3. Go to Application → Cookies → youtube.com
4. Look for cookies: `__Secure-1PSID`, `__Secure-3PSID`, `CONSENT`
5. Export format should be Netscape cookies format

## Using Cookies in SPVB Downloader

### In the Frontend

When entering a URL to download:
1. Look for "Advanced Options" or "Cookies" section
2. Paste your exported cookies (Netscape format)
3. Submit the download

### Cookie Format

Cookies must be in Netscape HTTP Cookie File format:

```
# Netscape HTTP Cookie File
# http://curl.haxx.se/rfc/cookie_spec.html
# This file was generated by get_cookies.txt! Edit at your own risk.

.youtube.com	TRUE	/	FALSE	1924991234	__Secure-1PSID	your-cookie-value-here
.youtube.com	TRUE	/	FALSE	1924991234	CONSENT	YES+your-value
...
```

## Troubleshooting

### Error: "Sign in to confirm you're not a bot"

**Solutions (in order):**
1. Provide fresh YouTube cookies (export new ones)
2. Wait 1-2 hours before retrying (rate limit cooldown)
3. Try from a different device/network
4. Ensure cookies are in Netscape format
5. Make sure cookies are not expired

### Error: "Forbidden (403)"

This usually means:
- Cookies are expired → export new ones
- Video is region-blocked → cookies from that region may help
- Account restrictions → use a different YouTube account

### Error: "Video not available"

The video may be:
- Deleted
- Private (requires account with access)
- Age-restricted without cookies
- Region-restricted globally

## Testing Your Cookies

You can test if cookies are working by trying to download an age-restricted video:
- Example URL: `https://www.youtube.com/watch?v=EXTz7NqaHac` (age-restricted music)

If download succeeds with your cookies but fails without them, your cookies are working.

## Privacy & Security

⚠️ **Important:**
- Cookies contain your authentication info
- Keep them private, don't share publicly
- Cookies may expire (usually valid for 30-90 days)
- Export fresh cookies if downloads start failing
- Never paste cookies in public forums or screenshots

## Automatic Extraction

The downloader can extract cookies in real-time if you:
1. Provide a cookies file in Netscape format
2. Paste the raw Netscape cookie text
3. Use the browser extraction script

The system will:
- Automatically detect expired cookies
- Use fresh cookies for each download
- Clean up temporary cookie files
- Never store cookies permanently

## Best Practices

1. **Keep cookies fresh** - Export new cookies every 2 months
2. **Use a dedicated account** - Create a separate YouTube account just for downloads
3. **Monitor rate limits** - If you get "bot" errors, wait before retrying
4. **Test with public videos first** - Ensure basic downloads work before trying restricted content
5. **Backup cookies** - Save your exported cookies in a safe location

## Technical Details

The SPVB Downloader:
- Uses yt-dlp for YouTube extraction
- Accepts Netscape format cookies
- Creates temporary cookie files during download
- Automatically cleans up cookie files after download
- Supports per-download cookie configuration

Cookie requirements:
- Format: Netscape HTTP Cookie File (text file)
- Must include: CONSENT, __Secure-1PSID cookies
- Not needed for: Public, non-age-restricted videos
- Expires: Usually 30-90 days from export date
